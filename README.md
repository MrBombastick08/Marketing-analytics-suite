# Кластеризация и Анализ Данных

Приложение на Python, предназначенное для автоматизированной сегментации данных. Инструмент позволяет проводитьглубокий разведочный анализ, подбирать оптимальные параметры машинного обучения и формировать качественную отчетность для бизнеса.

------------------------------------------------------------------------

## ✨ Функциональные возможности

-   **Импорт данных:** Свободный выбор любого CSV-файла через
    стандартный проводник операционной системы.

### Интерактивный Dashboard (Вкладки)

-   **📋 Обзор:**\
    Мгновенный расчет статистики (среднее значение, минимум/максимум,
    стандартное отклонение) и проверка данных на целостность (поиск
    пропусков NaN).

-   **🔥 Связи:**\
    Тепловая карта корреляций для выявления скрытых зависимостей между
    различными признаками.

-   **📈 Подбор K:**\
    Визуализация *Метода локтя* и расчет **Силуэтного коэффициента** для
    научно обоснованного выбора количества кластеров.

-   **🎯 Кластеры:**\
    Сегментация данных алгоритмом **K-Means** с наглядным графиком
    распределения.

-   **🌲 Дерево:**\
    Иерархическая кластеризация с автоматическим построением
    **дендрограммы**.

------------------------------------------------------------------------

## 📤 Экспорт и отчетность

-   Сохранение любого сгенерированного графика в формате `.png` в
    высоком разрешении **(300 DPI)** для презентаций.
-   Генерация подробного аналитического отчета с использованием таблиц в
    формате **Markdown (`.md`)** и возможностью сохранения в файл.

------------------------------------------------------------------------

Современный адаптивный интерфейс с поддержкой **темной темы**,
реализованный на базе библиотеки `customtkinter`.

# 🚀 Инструкция по запуску

## 1️⃣ Требования

Для корректной работы приложения требуется установленный:

**Python версии 3.8 или выше**

------------------------------------------------------------------------

## 2️⃣ Установка зависимостей

Перед первым запуском необходимо установить все требуемые библиотеки.

``` bash
pip install customtkinter pandas matplotlib scikit-learn scipy seaborn tabulate
```

------------------------------------------------------------------------

## 3️⃣ Запуск программы

Запустите основной файл скрипта (например `main.py`):

``` bash
python main.py
```

------------------------------------------------------------------------

# 📈 Порядок работы с инструментом

### 1️⃣ Загрузка данных

Нажмите кнопку **"Открыть CSV"** и выберите файл.\
Вкладка **"Обзор"** автоматически покажет структуру данных и наличие
пропусков.

### 2️⃣ Анализ связей

Перейдите во вкладку **"Связи"**, чтобы определить параметры, наиболее
связанные между собой.

### 3️⃣ Определение числа кластеров

Используйте вкладку **"Подбор K"**:

-   найдите **точку излома** на графике метода локтя\
-   или **максимум** на графике силуэтного коэффициента

Это позволит определить оптимальное число кластеров.

### 4️⃣ Кластеризация

Введите выбранное значение в поле **"Число кластеров"** и нажмите:

**"Запустить анализ"**

### 5️⃣ Сохранение результатов

-   сохраните графики кнопкой **Save**
-   сформируйте **Markdown-отчет** для проекта или отправки коллегам.
